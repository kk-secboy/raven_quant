# 交易纪律 v1.0
生效日：2026-08-10。用户手动执行，Codex 只负责研究、条件计划和复盘。

## 先决条件

1. 任何计划必须写清证券、方向、触发价或触发条件、数量上限、失效条件和原因；缺一项不交易。
2. 用户没有确认的持仓、成交、现金或成本一律不得推断。每笔成交由用户在当日告知后才能进入账本。
3. 关键行情、公告或证券身份无法核实时，不新增风险；可以维持原仓或按预定防守条件减仓。
4. A股遵守 T+1、100股申报单位、涨跌停、停牌和费用约束。当天买入的股票不安排当天卖出。

## 仓位与集中度

1. 在账户总资产和现金未确认前，禁止计算完整总仓位，禁止新增第五只个股。
2. 完整账户数据确认后：单只普通股票目标不超过总资产25%，高波动题材股不超过15%，单一产业链不超过40%，现金通常保留15%以上。
3. 若某只股票因上涨超过30%，只允许持有或分批降回目标，不允许继续加仓。
4. 单日新增风险不超过账户总资产5%；每次试错以100股为基本单位，除非股价和总资产使其不合理。

## 执行纪律

1. 09:30-09:45不主动追价；高开超过3%不追，涨停或接近涨停不买。
2. 周内涨幅超过15%的证券不在次日开盘追加，只观察回踩承接或放量突破后的下一次确认。
3. 加仓只允许发生在：日线趋势未破、完成周期放量确认、行业强度同步、重要公告核验无异常四项同时满足时。
4. 减仓优先采用分批100-300股；不得因不愿承认错误而把交易仓变成长线仓。
5. 同一证券当天只做一次主动决策，避免情绪化反复交易。
6. 任何临时消息只作为线索；没有交易所或公司公告交叉验证，不据此下单。

## 风险纪律

1. 单日账户亏损达到前一日净值2%后，停止一切新增仓位。
2. 单周回撤达到4%时，下周首日禁止新增风险；先复盘错误来源。
3. 持仓跌破事前失效位时按计划减仓，不以成本价作为唯一支撑。
4. 财报、业绩预告、监管风险、定增、解禁、异常波动公告前后，降低仓位或提高确认门槛。
5. 浮盈不是安全垫。快速上涨后放量滞涨、冲高回落或跌破关键均线，优先保护本金和已获利润。

## 复盘纪律

每次复盘必须覆盖：基本面、投资逻辑、资金与成交、技术、市场情绪、公告与新闻；并记录计划内/计划外操作、成功、错误、机会成本、下一期改进。评价决策质量时区分“过程正确但亏损”和“过程错误但盈利”。
