# 外围参考数据计划(backlog,减重验收后实施)

> 状态:待实施。前置条件:减重版在服务器连续两周无人值守验收通过。
> 来源:2026-09-01 减重会话中确认的切法。原则:只加数据,不加功能;粒度到行业指数为止。

## 目标

为 A 股研究主线提供外围传导特征:隔夜外盘涨跌、行业板块传导、利率环境。
外围数据只作为**因子候选源**,进入既有的外部因子评估/验货通道,不直接进入任何策略。

## 数据清单(一个数据集装下)

| 层 | 内容 | 用途 |
| --- | --- | --- |
| 宽基 | 标普500、纳指、道指、恒生、恒生科技 | 大盘情绪 |
| 行业指数 | 费城半导体(SOX)等 GICS 二/三级行业指数,几十个系列 | 板块传导(与申万行业映射) |
| 龙头个股 | 英伟达等少量产业链龙头(十只以内) | 龙头带动效应 |
| 利率/汇率 | 美债 10Y 收益率、美元指数 | 利率环境 |

明确不做:美股/港股全市场管道、个股级全细分、分钟级、任何外盘交易关联。

## 数据源

- 首选 Tushare 全球指数/利率接口;个股如 Tushare 权限不足,评估替代源(只读公共行情)
- 实施前先跑通权限验证(probe),缺权限不硬做、不伪造覆盖

## 工程接入(复用现有纪律,不发明第二条管道)

1. `catalog.py` 注册数据集(如 `global_reference_daily`),主键、字段、allow_empty 语义
2. `availability.py` 注册 PIT 政策:外盘收盘早于 A 股开盘,当日盘前可用(精确到具体时间源字段)
3. 下载走既有 work-unit/checkpoint/限速/幂等管道;落不可变快照
4. 质量门接入 verify;`recoverability` 标注
5. 因子化:隔夜涨跌幅、行业指数动量等,走 `register_external_factor` 通道进因子候选
6. 测试:下载规划、PIT 可见性(隔夜边界)、因子 artifact 确定性重跑

## 顺带两项数据旧账

1. **宏观补历史**:cn_cpi/cn_ppi/cn_pmi/cn_m/sf_month/shibor/lpr 当前仅 2024 年起,补到 2016(与研究窗口对齐)
2. **npr 排查**:国家政策法规库 964 个成功单元但 0 行,查明是接口权限还是解析问题;确认不可用则从生产目录边界移除并记录

## 验收

- 数据集落盘 + verify 通过 + 快照 manifest 完整
- 至少一个外围因子完成外部因子评估(过不过门都算结论)
- 全程不触碰 A 股既有快照与 Qlib 数据集身份
