# 个人持仓辅助决策档案

本目录用于用户真实持仓的研究、计划与复盘。Codex 不连接券商、不读取账户、不代替用户下单，也不把建议当作保证收益的指令。

## 权威边界

- `state/holdings.csv`：用户最后确认的持仓事实。任何成交、分红、送转、成本变化、现金变化都必须由用户确认后更新。
- `policy/trading_discipline.md`：交易纪律和风险上限。
- `plans/`：事前交易计划；不得用盘后信息改写。
- `reports/daily|weekly|monthly|quarterly/`：复盘报告。
- `journal/trades.csv`：用户确认的真实成交记录。没有确认不得推断或补记。
- `journal/mistakes.md`：成功、失误和待改进事项。
