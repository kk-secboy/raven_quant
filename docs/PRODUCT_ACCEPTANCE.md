# QuantLab 正式可用验收清单

本文把《如何搭建自己的量化交易系统》的要求映射到当前 Python + Qlib + RD-Agent
实现。数据下载与产品开发并行推进；任何模块只有通过验收门禁才标记为可用。

## 当前结论

代码完成不等于运行环境已验收。任务页的“正式可用验收”现在从数据库、任务、
不可变数据集和运行健康记录实时计算六个验收层级：研究与回测、配对研究、
配对模拟盘、模拟盘、券商沙箱和多策略模拟盘。
任何一层存在阻塞项都不会显示为可用，实盘交易在所有层级均明确禁用。

## 开发顺序

1. 完成当前 A 股日频初始化、质量校验和 Qlib 快照。
2. 完成第一套行业约束指数增强策略及真实 A 股撮合回测。
3. 打通因子晋级、策略版本、审批和模拟组合的端到端流程。
4. 在至少两套低相关策略上通过风险平价主组合和五个对齐交易日验收。
5. 运行已接入数据中心的 `cn_margin_eligibility` 和 `pair_execution_1m`，验收真实权限、覆盖率与不可变快照，再完成首个配对策略的原生回测和第二人审批。
6. 用已实现的专用双腿价差账本连续运行至少 5 个对齐交易日并通过 `pair_paper` 门禁。
7. 连续运行普通与配对模拟盘并完成风险、告警、恢复和对账验收。
8. 接入 QMT 模拟环境；在人工批准前保持实盘交易禁用。
9. 再扩展外围市场策略和确有收益的数据层。

## 第一套可用策略验收

- 市场：A 股；基准为沪深 300 或中证 500。
- 组合：行业约束多因子指数增强，资金规模按 500 万元验证。
- 执行：收盘生成信号，下一交易日开盘执行。
- 成本：买入、卖出、印花税、滑点和成交额参与率均计入。
- 交易限制：停牌、涨停买入、跌停卖出必须被撮合层拒绝。
- 验证：至少 504 个交易日，并包含滚动样本外、成本翻倍和历史压力测试。
- 风险：最大回撤不超过 10%，跟踪误差、换手、行业暴露和容量均有硬门禁。
- 治理：未通过回测门禁的策略版本不能审批，未审批版本不能进入模拟盘。
