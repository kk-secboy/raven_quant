# QuantLab 金融、数学与投资正确性审计（2026-08-25）

## 结论边界

代码中已经有较完整的 PIT、统计检验、成本、A 股执行限制和模拟账本保护。
本轮轻量审计没有发现能够让现有核心单元测试直接失败的新数学错误，但这不等于
策略有效，也不等于服务器全历史正式回测已经通过。

必须把三件事分开：

1. 公式和账本是否算对；
2. 回测是否没有未来数据、幸存者偏差和不现实成交；
3. 策略在真实样本外是否仍有收益。

前两项是软件正确性，第三项只能由冻结数据、正式 OOS 和模拟盘回答。

## 审计方法

| 审计域 | 检查方法 | 失败时的处理 |
| --- | --- | --- |
| 收益、波动、Sharpe、回撤 | 手算小路径，与实现逐项对照；零方差和样本不足必须返回未定义 | 禁止用 0 或无穷大伪装有效成绩 |
| 现金流和净值 | 注入/取出现金前后比较单位净值；TWR、XIRR、NAV 分开计算 | 不守恒立即进入 safe mode |
| 费用 | 买卖佣金、最低佣金、印花税、过户费、滑点和冲击逐笔复算 | 交易日期没有对应费率版本时 fail-closed |
| A 股交易规则 | next-bar、涨跌停、停牌、整手、T+1、参与率、部分成交 | 同 Bar 或不可成交订单必须拒绝 |
| 公司行动 | 拆股、分红、税负和应收前后验证总资产守恒 | 缺少 PIT 公司行动证据时不入账 |
| PIT | 截止日重算；追加未来行后历史值不能改变 | 未来引用、bfill、负向 Ref 特征直接拒绝 |
| 股票池 | 使用历史成分、上市/退市和可交易状态；保留退市证券 | 当前成分回填历史即判定为幸存者偏差 |
| 训练与测试 | purge、embargo、外层 walk-forward、最终 OOS 一次性消费 | 窗口重叠或重复打开最终样本即阻断 |
| 多重试验 | HAC、BH/Holm、DSR、PBO、配对区块 bootstrap、消融 | 官方或 RD-Agent 内部单次最好成绩不能晋级 |
| 历史/模拟一致性 | 同一冻结订单计划在两套执行核心做差分 | 成交、费用、现金或持仓不一致即阻断发布 |

覆盖：统计检验、正式验证窗口、成本模型、单位化收益、next-bar、执行算法、
组合优化、模拟执行、历史/模拟差分、PIT 和安慰剂泄漏诊断。

已确认的关键实现：

- 因子表达式禁止未来引用；Python 因子执行追加未来数据前缀不变性测试。
- 最终 OOS 与预最终历史分离，并要求 purge/embargo。
- 正式成本按交易日期选择 2015、2022、2023 三段费率版本。
- 股票 T+1、停牌、涨跌停、整手、成交量参与率和 next-bar 都进入执行合同。
- 外部现金流使用单位化 TWR，不允许充值制造收益或掩盖回撤。
- RD-Agent 成绩只作反馈，晋级读取独立 Qlib 复算和多重检验证据。

## 尚未被本轮证明的事项

- 尚未在本机运行全量 Qlib、RD-Agent 或数据库测试，符合低负载约束。
- 服务器需要用冻结全历史数据执行一次正式差分、公司行动和退市证券验收。
- `run_qlib_baseline.py` 是 Alpha158 + LightGBM 的探索基线，使用固定比例切分和
  简化 TopK 回测；它不能代替正式策略验证，也不能直接审批。
- 任何因子、模型或 SOTA 仍需真实最终 OOS 和至少约半年模拟盘，不能由代码测试
  推导出投资价值。

## 发布硬门

以后每个发布版本至少保留以下结论：

- `math_core`: 手算与性质测试通过；
- `pit`: 截止日与前缀不变性通过；
- `execution_differential`: 历史与模拟执行一致；
- `dataset_lineage`: 快照和 Qlib 血缘完整；
- `formal_oos`: 最终样本只消费一次；
- `paper_forward`: 只记录真实前向结果，不回填。

任何一项未知或失败，都只能显示“研究中/阻断”，不能显示“可投资”。
