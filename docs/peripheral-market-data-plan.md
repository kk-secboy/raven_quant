# 外围数据接入计划(backlog)

> 状态:待实施。前置条件:减重版在服务器连续两周无人值守验收通过。
> 2026-09-02 修订:经服务器实测,美股/港股/美债/全球指数数据已在每日自动下载(美股日线约千万行、港股日线 137 万行、美债收益率、index_global),本计划主题从"新建下载"改为"接入研究主线 + 补漏"。

## 目标

把已下载的外围数据接入研究主线,作为**因子候选源**进入既有外部因子评估通道;补齐宏观历史与新闻缺口。只加数据,不加功能;系统仍只做 A 股 + 场内 ETF 模拟,不建外围交易管道。

## 勘察结论(2026-09-02 服务器生产库实测)

已存在且每日自动下载:美股日线/复权(各约 1000 万行)、美股财报、us_basic、港股日线/分钟/财报、index_global、美债收益率(us_tycr 等 5 接口)、美股交易日历。

真正缺口:

1. 外围数据只下载未接入:无 PIT 可用时间政策、不进快照、不进 Qlib、无因子化
2. GICS 二/三级行业指数(费城半导体等)在 index_global 中的覆盖待 probe 核实
3. 宏观数据(cn_cpi/cn_ppi/cn_pmi/cn_m/sf_month/shibor/shibor_lpr)仅 2024 年起
4. npr(国家政策法规库)964 个成功单元但 0 行
5. 龙头个股数据已有(us_daily),只需白名单配置

## 阶段

- **A. 数据源验证(只读)**:~~index_global 指数清单核对~~ 已完成(2026-09-02):index_global 共 22 支,宽基齐全(SPX/IXIC/DJI/RUT/HSI/HKTECH/N225 等),**无费城半导体等细分行业指数**——行业传导层改用"半导体龙头篮子"(NVDA/TSM/AVGO 等,us_daily 已有数据,等权合成)近似,不引入新数据源;美债接口字段语义待实施时核;龙头白名单(默认十只以内)
- **B. PIT 与快照接入(核心)**:availability.py 注册外围可用时间政策(外盘收盘 → A 股盘前可用,fail-closed);外围数据进独立快照(不动 A 股主快照与 Qlib 数据集身份);verify 质量门扩展
- **C. 外围因子化**:隔夜涨跌幅、行业指数动量、美债收益率变化等纯结构化因子(无 LLM),经 register_external_factor 走既有评估通道;龙头对 A 股产业链映射用确定性规则(参照 major_news_mentions)
- **D. 缺口补漏**:cn_macro 回补 2016-2023;npr 排查(权限或解析),不可用则从目录边界移除并记录

## 验收

- 外围独立快照落盘 + verify 通过
- 至少 3 个外围因子完成外部因子评估(过不过门都算结论)
- A 股主快照与 Qlib 数据集身份零变化(identity 哈希前后一致)
- 缺权限就缩小范围,不硬做、不伪造覆盖
